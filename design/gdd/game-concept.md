## Elevator Pitch

> 《口袋桌游厅》是一款免下载、手机与电脑网页互通的在线经典桌游平台：你只需甩出一个房间链接，好友无需注册即可快速入座，还原中式经典飞行棋、极速大富翁等纸质桌游并自由开关熟人“村规”，享受零广告、无氪金、随时随地创造快乐的实体桌面体验。
>
> *10 秒理解测试*：打开网页点开链接 → 免登录一键入座 → 选好自家村规 → 和远近好友一起掷骰走子、撞飞对手，打完一局 10–15 分钟再原地一键复开或换盘。

## Core Fantasy

**「口袋里永远揣着一整箱随时能摊开的实体桌游。」**

无论是线下和朋友聚在咖啡馆、宿舍或饭局却没带实体棋盒（每人各自用手机扫码/点链接连入同一张线上房桌），还是好友散落不同城市想在电脑或手机上远程开黑，只要发一个房间链接，大家免安装、免注册一键入座，就能聚到同一张阳光暖木桌前，掷出第一颗清脆的骰子，重温纸质桌游最纯粹的哄笑、起飞、撞飞与翻盘时刻。

- **场景边界澄清**：MVP 至 Alpha 阶段聚焦**多端实时在线同步房间**（面对面聚会时每人各自持手机接入同一房间）；**离线单机同屏传玩（Pass-and-Play）**明确留作 Full Vision 增强项，不在早期阶段透支开发承诺。
- **方案取舍理由（Rationales & Alternatives Considered）**：头脑风暴阶段共评估了 3 个创意方向——
  1. **《口袋桌游厅》（选定 · Verb-first）**：紧扣用户“随手替代纸质桌游、跨越手机与电脑远程同乐”的初衷，以低门槛经典规则 + 自由村规建立最大公约数，单人业余节奏可稳步分期落地；
  2. *《骰子捣蛋屋》（弃选 · Mashup）*：每接入一款经典桌游都要重做并平衡一套整活道具卡池，与个人首次开发、可控迭代的目标冲突；
  3. *《围炉小桌》（弃选 · Experience-first）*：强实时共在桌面动作与跨天异步续局在 375px 手机竖屏下易挤压棋盘可读性并拉高首版门槛（其“好友趣味称号战报、轻量表情催促”已精简吸收至本作）。

## Unique Hook

> **像《世界游戏大全 51》那样具备清脆克制的实体棋盘触感，像 Gartic Phone / PlayingCards.io 一样独立网页免登录甩链接秒入座，而且彻底剔除微信小游戏常见的广告弹窗、房卡体力与氪金骰子，把熟人聚会最在意的「零广告纯公平 + 本土经典村规自由开关」做到极致的跨端桌面。**

- **竞品参照校正说明**：不以偏重度德式策略的 Board Game Arena (BGA) 为唯一参照，而是直面熟人局的真实竞品（微信飞行棋/大富翁小游戏、Gartic Phone / PlayingCards.io、《世界游戏大全 51》），用独立跨端网页的无摩擦与实体质感，把被商业化污染的经典纸质桌游还给熟人聚会本身。

## Player Experience Analysis (MDA Framework)

### Target Aesthetics (What the player FEELS)

| Aesthetic | Priority | How We Deliver It |
| ---- | ---- | ---- |
| **Fellowship**（社交联结） | **1（核心首位）** | 极速免注册入桌、同房一键 Rematch 与 10 秒换盘、房主定制熟人村规、局内 2–3 个轻量静态表情/敲桌催促气泡（MVP 即具备）与局末趣味称号战报（Vertical Slice） |
| **Sensation**（实体视听触感） | **2（差异化核心）** | 「阳光纸木桌游箱」2.5D 厚卡纸与双层接触影、清脆木/纸敲击与骰子落桌音、单步 ≤ 0.8s 弹性跃迁与撞飞顿帧（无光污染） |
| **Challenge**（轻博弈与悬念） | **3（局内波峰）** | 中式经典飞行棋同色连跳/虚线飞跃航线带来的追击、卡位、叠子与撞回基地风险博弈；后续《极速大富翁》的有限回合资产决策 |
| **Narrative**（涌现故事感） | **4（熟人名场面）** | 连掷三个 6 全军回基地、临门一脚被好兄弟撞飞、村规首次触发 2.5–3.5s 轻提示条引发全桌哄笑，以及局末趣味战报梗 |
| **Submission**（放松解压） | **5（低压力氛围）** | 明亮柔和的午后咖啡馆日光桌台、单局 10–15 分钟随时停桌、无段位天梯、无每日打卡焦虑 |
| **Expression**（轻量个性化） | **6（辅助）** | 房主对“自家村规”的组合署名权、预填可改昵称与四色双通道棋子、对局中的即时情绪表情气泡 |
| **Fantasy**（怀旧拟真幻想） | **7（底座氛围）** | “口袋里随时摊开一盒精致实体纸木桌游”的触手可及感，统一左上 45° 自然漫射光与厚纸板微立体语言 |
| **Discovery**（规则探索） | **N/A（极低）** | 本作主打“零学习成本的经典老游戏”，熟悉规则即核心优势 |

### Key Dynamics (Emergent player behaviors)

- **“定村规仪式感”**：开局前好友在微信/语音里争论“要不要开 5/6 起飞？要不要开三连 6 回老家？”，房主点两下开关，全桌角标立刻亮起。
- **“吃瓜与起哄共鸣”**：即使未开外挂语音，有人掷出 6 飞跃全图或撞飞领跑者时，全桌玩家可立刻点 2–3 个极简表情/敲桌催促气泡互动，维持聚会温度。
- **“人不够 AI 凑，断线不冷场”**：2–3 人想开 4 人局时随手补 AI；聚会中途有人切微信或掉线，经连续超时衰减后 AI 快速接管并在本人点击屏幕时秒级还权；房主掉线超时自动移交房主权，整桌永不死锁。
- **“一桌不断席连玩”**：打完一局一键原地 Rematch（MVP 起支持），Alpha-1 起支持 10 秒原地换盘切换另一款原生 2–4 人经典桌游，全员同时上桌不坐冷板凳。

### Core Mechanics (Systems we build)

1. **极速无账号房间与权威状态同步壳层**：一键建房生成短链接/房号，预填随机昵称支持 1 步入座；服务端权威 `stateSeq` 全量快照驱动同步，含大厅 60–120s 宽容、连续超时衰减与房主超时自动移交（Host Migration）。
2. **中式经典飞行棋权威规则引擎（首发）**：完整实现四色停机坪、起飞点、52 格外圈主航道、同色连跳、虚线快捷飞跃航线、终点折返/精准入终及叠子/撞机规则；默认采用**极速经典预设（每方 2–3 架飞机 + 首架预置待飞/5–6 起飞）**确保数学上稳定落在 10–15 分钟，传统 4 架飞机完整局作为预设可选项。
3. **实体触感与 `375×540px dvh` 竖屏防误触交互层**：零滚动视口布局 + 底部互斥操作槽（骰子区与编号快捷选子条按阶段切换）+ 1 点预览落点/撞飞预警、2 点确认走子 + 独立位置唯一合法步大按钮 + 单步 ≤ 0.8s（链式 ≤ 1.5s）动效与 Web Audio 音效。
4. **桌角村规铭牌与首次触发 2.5–3.5s 轻提示系统（MVP 即包含极简版）**：常驻显示当前偏离默认值的自定义村规文字标签，并在局内某条村规首次生效时弹出 2.5–3.5 秒非阻塞提示条（可轻点收起），消除秒进好友困惑。
5. **可插拔游戏规则状态机接口（`ADR-001`）**：将平台房间壳与每款游戏的纯函数状态机隔离，通过统一 `GameModule` 契约接入后续 2–4 人超轻量经典二游（Alpha-1）与《极速大富翁》（Alpha-2）。

## Player Motivation Profile

### Primary Psychological Needs Served (SDT / PENS)

| Need | How This Game Satisfies It | Strength |
| ---- | ---- | ---- |
| **Relatedness**（归属与联结） | 全作品核心驱动力：零门槛拉熟人同桌玩同一局、实时可见彼此掷骰与撞飞结果、极简表情/催促气泡与趣味战报共同回忆 | **Core** |
| **Autonomy**（自主与掌控） | 房主与好友可自由开关村规、决定聚会节奏与何时换盘、随时加减 AI 补位、保留玩家亲手点选走子的实体掌控感，无任何日常任务束缚 | **Core** |
| **Competence**（胜任与策略感） | 棋盘局势一目了然、落点虚线与撞飞预警清晰可见，在起飞、叠子防御、追击撞飞与大富翁有限回合买地之间做轻策略抉择 | **Supporting** |

### Player Type Appeal (Bartle & Quantic Foundry)

- [x] **Socializers（社交陪伴型 · 首要目标玩家）** — 看重与熟人共度低门槛快乐时光，反感重操作与陌生人戾气。
- [x] **Competitors / Killers（轻竞技/整蛊型 · 次要吸引力）** — 喜欢把朋友飞机撞回老家或用高额租金逆转收割的爽快感，不追求全服天梯。
- [x] **Achievers（目标达成型 · 辅助吸引力）** — 在 10–15 分钟内率先全机冲线或总资产第一，收获当场趣味战报称号与本桌连局记分。
- [ ] **Explorers（探索机制型 · 非主力）** — 经典熟悉规则为主，无复杂隐藏机制探索空间。

**明确不适合谁**：重度德式精算玩家、跨服天梯冲分竞技党、期待单人长线剧情或海量收集养成的玩家。

### Flow State Design

- **Onboarding curve（极速无摩擦入座）**：点开链接后默认预填趣味随机昵称并自动分配空座，1 次点击即可入座（避免手机输入法阻塞 5–8 秒）；入局后高亮合法可走棋子，点击棋子/底部编号卡即刻显示落点虚线与撞飞预警，村规首次触发附带 2.5–3.5s 可读提示条。
- **Difficulty scaling**：默认“极速经典”轻松上手；熟人可逐步开启特色村规、传统 4 架飞机完整局或后续《极速大富翁》。
- **Feedback clarity**：每次掷骰、起飞、同色连跳、虚线飞跃与撞飞均有清晰节奏与独立视觉反馈（静音手机同样完整可辨）。
- **Recovery from failure**：默认单局 10–15 分钟，大富翁采用固定回合总资产或首破产即结算消除坐牢观战，局末 1 次点击原地 Rematch，败局只化作熟人谈资。

## Core Loop

### Moment-to-Moment (30 seconds)
1. **轮次触发与催促**：轮到自己回合时座位呼吸脉冲高亮（纯视觉在静音模式下同样明确）；若玩家走神，好友可发轻量“敲桌催一催”气泡；单步超时 30 秒触发 AI 代走，且支持**连续超时衰减**（连续 ≥ 2 次超时或确认断连后自动切入临时托管，AI 2–3 秒代走，本人任意点击屏幕立刻接回）。
2. **掷骰与选子（无 Hover 触屏模型）**：点击底部操作槽的骰子区，触发短促物理弹跳与落桌音；掷出后底部同一操作槽互斥切换为**带 1–4 编号与位置摘要的快捷选子条**。
   - **多合法步**：点击棋盘棋子或底部对应编号卡 → **第 1 次点击预览精确落点虚线与撞飞预警** → **第 2 次点击或点大号“确认走子”按钮执行**。
   - **唯一合法步**：在独立于掷骰区的位置（或施加 300ms 输入防抖）呈现大号“确认走子”按钮，保留亲手走子的掌控感（“唯一步全自动直走”仅作为老手可选开关）。
3. **弹性走子与事件反馈**：单次普通走子动画 **≤ 0.8 秒**；若触发同色连跳 + 虚线飞跃 + 撞飞回巢等链式复合事件，自动压缩步间间隔并将**整次链式动画总时长硬控在 ≤ 1.5 秒**；同时全桌可通过 2–3 个轻量静态表情共鸣。

### Short-Term (5–15 minutes)
完整的单局攻防周期：**起飞破冰 → 中盘追击与卡位博弈 → 终盘精准冲线**。
- **中式经典飞行棋基准与时长校准**：锁定国内玩家最熟悉的**中式经典飞行棋**（52 格外圈 + 同色向前连跳 4 格 + 专属虚线飞跃航线，而非无飞跃航线的西式 Ludo）。由于传统 4 人 4 架飞机耗时通常达 25–45 分钟，本平台将默认开局预设校准为 **“极速经典（Express Classic）”**（默认每方 **2–3 架飞机**，具体数量由原型实测锁定，配合首架预置待飞或 5/6 起飞），从规则数学上稳定兑现 **10–15 分钟单局** 且完整保留终盘撞飞反超张力；**传统 4 架飞机完整标准局（20–35 分钟）**作为可选预设供慢玩好友切换。

### Session-Level (30–120 minutes)
好友晚间/周末连开 **3–5 局**：一键原地 Rematch（MVP 起支持）→ 局间房主可微调村规开关 → Alpha-1 起 10 秒原地换盘切换其他原生 2–4 人经典桌游 → 房间内存维护轻量连局胜场记分与局末趣味称号战报卡（Vertical Slice）。

### Long-Term Progression & Retention Hooks
- **无数值养成与 FOMO 捆绑**：零账号、零排位、零体力锁。
- **Social（核心）**：群里随时甩链接 1 步入座，成为好友常驻微信收藏夹的便携桌游箱。
- **Curiosity / Mastery / Investment**：逐步扩充的 2–4 人经典桌游目录、自定义村规组合探索、本地记忆常用昵称与偏好预设。

## Game Pillars & Anti-Pillars

> 本支柱集已通过 `creative-director` **CD-PILLARS: APPROVE** 终审，并结合 `/design-review` 补齐了可测性、高度预算与 2–4 人选品边界；工程解耦需求记录为架构决策 **`ADR-001`**。

### Pillar 1: 十秒开桌，零摩擦入局（Ten-Second Table）
免下载、免注册、免浏览器权限弹窗，让好友点开分享链接后以最短系统响应与最少点击进入对局：
- **可测系统 SLA**：房主点击建房 → 生成可复制链接 **≤ 1.0s（P95）**；好友点击链接在 `Fast 4G`（1.6 Mbps / 150ms RTT、4x CPU 降速、禁用缓存）下首屏关键路径 gzip **≤ 200KB** 且可交互 **≤ 2.0s（P95）**；默认预填昵称 1 次点击入座看到棋盘 **≤ 8.0s**（不含外部聊天软件传输耗时）。
- *Design Test A（对抗 P3 配置膨胀）*：默认选中推荐预设、1 次点击即出房号，村规折叠进快切面板，好友入座无需通读规则长文即可开玩。
- *Design Test B（对抗 P2 资产膨胀）*：严守首屏 gzip ≤ 200KB 与 Fast 4G ≤ 2.0s 可交互硬预算，高阶视听资产一律首屏外渐进加载。

### Pillar 2: 指尖上的克制实体触感（Tactile Tabletop Feel）
隔着手机或电脑屏幕，每一次掷骰、走子、撞飞或结算都具备清脆、有物理重量且清晰易读的实体桌游视听反馈，坚决拒绝手游光污染，并严守 **`375×540px dvh` 手机竖屏零滚动铁律**。
- *Design Test A（克制实体感 vs 炫酷手游光效）*：撞飞对手或收巨额租金时，拒绝全屏光污染与 2 秒大招特写，选择克制的棋子碰撞弹飞、棋盘微震、短促顿帧与清脆木/纸敲击音效（单步 ≤ 0.8s，链式复合总时长 ≤ 1.5s）。
- *Design Test B（小屏棋盘与高度预算优先）*：在 `375×540px dvh`（微信内置浏览器 / iPhone SE 实际可视区）下，优先保障 ~355px 正方形棋盘主视野、底部互斥操作槽零滚动以及清晰编号选子，将次要日志与资产明细收入可展开抽屉。

### Pillar 3: 村规自由，透明不懵圈（Your House Rules, Transparently Yours）
尊重熟人“家家规矩不同”的习惯，每款游戏提供 2–3 套一键预设与 3–6 个高辨识村规开关；所有生效村规全程对全桌清晰可见、首次触发即给可读提示，**且村规开关与村规反馈绝不拆散到不同里程碑**。
- *Design Test A（双向边界）*：既不做死板单一官方规则，也不做 30 个数值滑块的硬核编辑器；限定预设 + 3–6 个精选开关（MVP 先落 1 套默认极速经典预设 + 1–2 个高频开关）。
- *Design Test B（局内规则透明底线）*：自 MVP 起，任何偏离默认值的自定义村规必须以极简文字徽标常驻桌角，并在该局首次触发时弹出 **2.5–3.5 秒**非阻塞可读提示条（支持轻点收起），杜绝秒进好友误以为出 Bug。

### Pillar 4: 一桌不断席，换盘不散场（One Living Table, Many Classics）
*(承载头号 MDA 美学目标 **Fellowship**)*
好友聚齐一次就能在同一张跨端牌桌上连开多局（MVP 即具备一键 Rematch）、10 秒原地换盘；**所有常驻换盘经典游戏必须原生支持 2–4 人同时参与（绝不强制旁观坐冷板凳）**；手机与 PC 共享一致的轻量桌面壳层，并通过连续超时衰减托管与房主超时自动移交，确保整桌绝不冷场散伙。
- *Design Test（对抗单游复杂度破坏统一壳层）*：接入后续《大富翁》时，拒绝 PC 专属多层阻塞交易弹窗，重塑为适配手机单手 2 步抽屉交互与默认 10–15 分钟极速胜负规则（固定回合总资产决胜或首破产即结算，传统无尽模式收进村规）。

### 跨支柱张力矩阵（Tension Matrix）

| 冲突张力对 | 核心设计冲突 | 本作明确平衡裁决 |
| ---- | ---- | ---- |
| **P1（十秒开桌）↔ P3（村规自由）** | 村规越多，开局越慢、秒进好友越易懵圈 | 1 键默认预设出房 + 折叠开关 + 常驻文字角标 + 首次触发 2.5–3.5s 轻提示 |
| **P1（十秒开桌）↔ P2（实体触感）** | 材质与动画拖慢首屏加载与回合节奏 | 首屏 gzip ≤ 200KB / Fast 4G ≤ 2.0s + 单步 ≤ 0.8s / 链式 ≤ 1.5s |
| **P2（实体触感）↔ P4（一桌多游）** | 复杂游戏专属面板 vs 375×540px 统一轻桌壳 | 底部互斥操作槽 + 2 步抽屉法裁剪大富翁 + 严选原生 2–4 人同时参与游戏 |

### Anti-Pillars (What This Game Is NOT)

- **NOT 强社交匹配与天梯排位大厅**：不做陌生人 MMR 排位与强制每日任务（保护 *Fellowship*）。*明确允许房主在人数不足 4 人时添加 AI 机器人补位。*
- **NOT 氪金数值、广告弹窗与房卡体力限制**：零广告轰炸、无付费改骰子、无房卡体力锁，守护纯公平实体桌游体验。
- **NOT 重度 3D 物理自由沙盒**：不做 Tabletop Simulator 式自由 3D 抓取摆子，由权威状态机校验合法走法防误操作。
- **NOT 重度内置音视频通话**：不自研 WebRTC 音视频，避免浏览器麦克风/摄像头权限弹窗打断入局（保护 P1），仅提供 2–3 个轻量静态表情与敲桌催促气泡。

## Visual Identity Anchor

*(经 `art-director` **AD-CONCEPT-VISUAL: CONCEPTS** 评审选定，并按 `/design-review` 完成色觉无障碍与对比度校准)*

- **方向名称**：**「阳光纸木桌游箱」（Sunlit Tabletop Craft）**
- **一句话视觉铁律**：**「桌面上的每一样东西，都必须看起来能被手指捏起来、放下去。」**
- **情绪与氛围目标**：午后靠窗咖啡馆木桌般的柔和自然日光（统一左上 45° 柔和漫射光），宁静低噪，仅当前可交互物体微浮起提示，彻底绝缘手游弹窗焦虑。
- **造型语言与无障碍双通道规范**：
  - **柔倒角厚卡纸（Soft-Chamfered Physical Geometry）**：圆润倒角 + 2–3px 卡纸底边厚度（bottom lip）+ 双层接触阴影构建轻量 2.5D 层次；MVP 阶段先以干净几何厚卡纸落地，高阶压纹与微纸纹打磨留待 Vertical Slice。
  - **真机可读的双通道棋子与棋盘编码（修复 24px 细微徽记不可读问题）**：
    - 放弃在 24px 棋子机身内绘制 8–10px 复杂细微图标，改为**外轮廓/机翼剪影微差异 + 棋子底托极简几何形状（圆/方/三角/菱形）+ 1–4 清晰编号**（便于与底部快捷选子条一一映射）；
    - **棋盘格与虚线航线同步双通道**：52 个外圈同色格、起飞点与虚线飞跃航线在 `/art-bible` 中必须与四色同步绑定对应的极简底纹符号或线型样式，确保色觉障碍玩家同样一眼识别“同色连跳”与“虚线飞跃”。
  - **村规铭牌实体化**：对局桌角常驻显示自定义村规标签，非默认魔改规则加盖醒目高对比角标/印章（吸收方向三巧思）。
- **支撑原则与设计检验**：
  1. **原则 A「抬起即交互（Elevation = Affordance）」**：可操作实体通过微浮起、分离投影与高对比外框传达可点性，而非堆砌文字引导气泡。
  2. **原则 B「一套桌台，百张棋纸（One Table Shell, Pluggable Game Sheets）」**：固定木桌台与统一光照/交互壳，新增游戏仅替换中央棋盘纸面与专属棋子。
  3. **原则 C「靠几何厚度与光影造触感，不靠重贴图」**：坚持按需重绘的轻量矢量 Canvas 2D + 原生 HTML/CSS 壳层，严禁多 MB 位图或重 3D 模型。
- **色彩哲学（经 WCAG AA 3:1 与防撞色校准）**：
  - **公共桌台与盘面（占画面 55%–65%）**：浅橡木/暖亚麻底色（`#E9DFCF` / `#F5EFE6`）+ 暖象牙白卡纸盘面（`#FAF7F2`）。
  - **格线、轮廓与字体**：深墨棕（`#2E2620`，**禁用纯黑 `#000000`**）。
  - **校准后日晒哑光四色**：珊瑚红（`#E05252`）、**深暖赭黄（校准自 `#E8A825` → `#C98A00` 并强制配深墨棕 `#2E2620` 外轮廓，确保在 `#FAF7F2` 上非文本对比度 ≥ 3:1）**、钴海蓝（`#3A7BD5`）、草甸绿（`#3E9C6B`）。
  - **交互高亮方案（消除原“暖琥珀”与黄色玩家撞色）**：改为**深墨棕高对比实线外框 + 亮白脉冲与抬升位移动画**，在红/黄/蓝/绿四色棋子与暖象牙盘面上均具备极强辨识度。
- **备选视觉方向与下游备忘**：曾对比方向二「明快几何桌游台」（实体温度偏弱）与方向三「怀旧平版印刷盒」（375px 小屏墨线更占边距、跨品类扩展成本略高，已吸收其魔改村规印章巧思）；`/art-bible` 阶段须正式锁定一套唯一统一的主材质家族语言，并在 `/ux-design` 与 `accessibility-specialist` 联合核验 24px 实机对比度。

### TD-FEASIBILITY 前置技术护栏（5 项核心约束）

1. **Snapshot-first 状态快照与动态动画缓冲**：以服务端单调递增 `stateSeq` 驱动全量快照；客户端携带 `expectedSeq` 与幂等 `actionId`；在线推送包同时携带终态快照与 `events[]`（按 `events[]` 预估时长动态对齐服务端动画缓冲窗，单步 ≤ 0.8s、链式复合 ≤ 1.5s），重连端跳过历史事件直渲染终态。
2. **分层断线恢复、连续超时衰减与房主移交**：大厅期保留房主与座位 60–120s（超时未归则触发 **Host Migration** 自动移交下一位在线真人）；局内单步超时 30s（+ 服务端宽限窗）触发 AI 代走，若**连续超时 ≥ 2 次或确认断连**则自动转入临时托管态（AI 2–3s 内代走），本人任意点击屏幕原子取回控制权。
3. **`375×540px dvh` 竖屏人因与防误触**：严格零滚动；底部单一互斥槽位按阶段切换“掷骰区”与“带 1–4 编号/位置摘要的快捷选子条”；棋盘格内以 `×2 / ×3` 叠子角标替代扇形展开；多合法步支持 1 点预览落点与撞飞预警、2 点确认走子；唯一合法步提供与掷骰区隔开的大号确认键；Canvas 棋盘暴露逻辑热区/轻量 DOM 覆盖层以支持 Playwright 稳定断言 `≥ 44px` 触控区。
4. **极简 `ADR-001` 纯函数 `GameModule` 契约**：隔离平台壳与游戏规则状态机（强制外部注入 `rng`、预留 `getViewForPlayer` 兼容未来暗牌游戏、严禁提前抽象跨游戏渲染引擎；完整签名细项如 `isGameOver`/`validateRules` 见下方交接约束）。
5. **硬性能预算与第 1 周真机网络探针（Week 1 Spike）**：
   - 首屏关键路径 JS+CSS（gzip）**≤ 200KB**，`Fast 4G`（1.6 Mbps / 150ms RTT、4x CPU 降速、禁用缓存）可交互 **≤ 2.0s（P95）**；动画期间 P95 帧耗时 ≤ 16.7ms（无实时 SVG 滤镜动画）；iOS 无震动 API 时以形变 + 独立接触影 + 顿帧 + Web Audio 为主力手感。
   - 严禁使用休眠 30–50s 的免费 PaaS；**第 1 周独立执行半天真机探针（Week 1 Spike）**，在真机微信（iOS + Android）与 iOS Safari 实测首开速度、443 端口 WSS 连通性及切后台 35s 重连恢复。

## Risks and Open Questions

### Design Risks
- **起飞卡死与单局超时**：通过默认“极速经典（2–3 架飞机 + 首架预置待飞/5–6 起飞）”从数学上锁住 10–15 分钟单局，保留传统 4 架标准局作预设。
- **中式飞行棋边缘口径分歧**：叠子上限、合体被撞、虚线飞跃后连跳与终点折返细节在 `/design-system` 飞行棋 GDD 锁死唯一默认规则表。
- **《极速大富翁》坐牢观战与小屏过载**：Alpha-2 强制默认 10–15 分钟固定回合总资产决胜/首破产即结算，棋盘格严禁塞地名密文，全部收进手机 2 步抽屉。

### Technical Risks
- **微信内置浏览器安全拦截、443 端口限制与 `localStorage` 孤岛**：准备自有域名 + 标准 TLS 并在 Week 1 Spike 实测；跨浏览器丢失 `seatToken` 提供“认领离线空位”兜底。
- **移动端 TCP 半开假在线与双标签页顶号风暴**：切回前台先发 1.5–2s 主动探活而非盲信 `readyState === OPEN`；双标签顶号下发专用关闭码 `4001` 禁止自动重连。
- **表现动画与服务端计时竞态**：通过 `expectedSeq`、`actionId` 幂等缓存、服务端相对 `remainingMs` 与动态动画缓冲窗化解。

### Market Risks
*(个人好友兴趣作品 `hobby`，无商业变现目标；下列外部阻力均未做行业量化调研：)*
- **熟人既有微信小游戏使用惯性**（*未调研*）：靠零广告、免下载跨端（手机/PC/微信互通）与自由村规口碑建立差异化。
- **无商业化下的服务器持续运维成本**（*未调研*）：控制极低月度运行成本（单节点轻量常驻进程 + 严格房间 TTL 清理）。

### Scope Risks
- **单人首次全栈多人工程量低估**：经 `PR-SCOPE` 与 `/design-review` 联合复核，全栈联机 MVP 实际约需 110–150 小时（单人业余节奏 **5–7 周**），已诚实调整 MVP 排期并补齐支柱守卫项（极简村规标签 + 3s Toast + 2–3 表情 + Rematch + 超时衰减与房主移交），避免为了虚假 3–4 周工期阉割核心体验。
- **第二作疲劳与大富翁叠加断层**：通过将 Alpha 拆分为 `Alpha-1`（2–4 人超轻量经典二游验证换盘）与 `Alpha-2`（《极速大富翁》专项里程碑）彻底解耦风险。

### Open Questions
1. **Week 1 Spike 真机结论**：目标托管方案在真机微信（iOS/Android）与 iOS Safari 下的首开耗时、4G/Wi-Fi 切换与 35s 切后台 WSS 恢复表现如何？
2. **中式飞行棋精确默认参数**：极速经典预设最终选 2 架还是 3 架飞机（由 `/prototype` 实测单局中位时长决定），以及叠子/虚线连跳边缘规则表？
3. **Alpha-1 2–4 人超轻量第 2 款游戏选型**：极简变色牌（UNO 精简版）、蛇梯棋还是吹牛骰最能在 2 周内验证“一桌不断席、换盘不散场”且最受熟人欢迎？
4. **服务端运行时与托管落地方案**：同仓 `shared/ + client/ + server/` 自建 Node+`ws` 还是边缘有状态托管房间服务（交由 `/create-architecture` 正式评估并写入 ADR）？

## MVP Definition

> 经 `PR-SCOPE` 与 `/design-review`（`creative-director` 综合裁决 + 用户拍板分歧 1 方案 A），诚实调整联机 MVP 周期为 **5–7 周（单人业余节奏，含第 1 周独立技术 Spike 门禁）**，守住全部四大支柱的最小可验证闭环。

**Core hypothesis（可证伪核心假设）**：
在封闭试玩（**N ≥ 5 组、每组 2–4 位真实熟人**）中，好友通过手机或电脑浏览器点击链接免注册入座（系统建房 ≤ 1s、Fast 4G 冷开可交互 ≤ 2s、1 步入座 ≤ 8s），能在 **0 次掉线永久死锁**的前提下打完单局中位时长 **10–15 分钟**的极速经典中式飞行棋（含村规可见反馈与极简表情互动），且 **≥ 60% 的对局在结束 60 秒内触发“原地再来一局”**。

**Required for MVP（5–7 周，单人业余节奏含缓冲）**：
1. **第 1 周技术探针门禁（Week 1 Spike）**：先部署极简公网 HTTPS/WSS（443 端口）Echo 房，在真机微信（iOS + Android）+ iOS Safari 验证 10 次切后台 35s 重连恢复与 4G 首开 ≤ 2s。
2. **无账号极速建房壳层与防死锁联机**：一键建房生成短链接/房号；预填随机昵称 1 步入座；2–4 人权威实时联机（`stateSeq` 快照 + `expectedSeq`/`actionId` 幂等）+ AI 补位 + 大厅 60–120s 保活 + **房主掉线超时自动移交（Host Migration）** + **30s 超时 AI 代走与连续超时衰减托管（本人点击秒级还权）** + 严格房间 TTL 清理。
3. **1 款完整首发游戏：中式经典飞行棋（极速经典默认预设）**：纯函数 `GameModule` 引擎（含确定性单测）+ 同色连跳/虚线飞跃航线 + 默认 2–3 架飞机极速预设（保 10–15 分钟）+ 1–2 个高频村规开关 + **桌角极简文字村规标签 + 首次触发 2.5–3.5s 非阻塞 Toast**。
4. **最小 Fellowship 闭环与混合触感**：**2–3 个轻量静态表情/敲桌催促气泡**（瞬时通道不占 `stateSeq`）+ **局末显式一键“再来一局（Rematch）”** + 一键静音开关 + 干净几何厚卡纸风格（按需重绘 Canvas 2D 棋盘 + 原生 HTML/CSS 壳层，`375×540px dvh` 零滚动、底部互斥槽、1 点预览/2 点确认、单步 ≤ 0.8s / 链式 ≤ 1.5s 动效与基础 Web Audio）。

**Explicitly NOT in MVP（按后续层级分批交付）**：
- 用户账号登录、好友列表、云端持久化数据库
- 第 3–4 项飞行棋村规、传统 4 架标准预设、实体压纹卡纸铭牌美术与微纸纹打磨（移至 Vertical Slice）
- 二维码扫描入房、独立桌面横屏双栏排版、完整 4–6 表情与局末趣味称号战报卡（移至 Vertical Slice）
- 多游戏原地换盘架构与原生 2–4 人超轻量第 2 款经典桌游（移至 Alpha-1）
- 《极速大富翁》全部规则与地产竞拍系统（独立移至 Alpha-2）
- 本地单机同屏传玩（Pass-and-Play）与可分享村规预设短链（移至 Full Vision）
- 内置音视频通话、陌生人天梯排位、广告/氪金/房卡体力（永久 Anti-Pillars）

## Downstream Handoff Constraints（下游设计 / 架构 / QA 交接清单）

*以下细项已由 `/design-review` 5 位专家明确，无需膨胀概念正文，直接交由对应下游技能强制承接：*

- **致 `/create-architecture` 与 `ADR-001`（`network-programmer` / `lead-programmer`）**：
  - 协议契约：维护最近 N 条 `actionId` 幂等结果缓存（明确区分 `ALREADY_APPLIED` 与过期拒收）；握手强制校验 `protocolVersion`（防微信旧缓存）；同设备双标签顶号下发专用关闭码 `4001: REPLACED_BY_NEW_SESSION`（前端禁自动重连）；严禁分享 URL 携带 `seatToken`；后台切回超 3s 先发 1.5–2s 主动 ping 探活；两阶段回合（掷骰 → 选子）明确倒计时归属、服务端 +1.5–2s 网络宽限窗与相对 `remainingMs`；全员真人离线时暂停游戏推进（防 AI 在 3 分钟 TTL 内独自打完）；明确旁观者上限、`MAX_ACTIVE_ROOMS` 硬上限与建房/表情速率限制；表情/催促走独立 ephemeral 广播通道不递增 `stateSeq`。
  - 工程边界：拆分 `shared/`（纯 TS 无 DOM 依赖）、`client/`（Vite 前端）与 `server/`（权威房间服）；补全 `GameModule` 完整签名（`isGameOver/getResult`、`validateRules`、`pickBotAction(..., rng)`、判别联合错误返回、按 `events[]` 计算确定性 `animDurationMs`）；限制前端运行时依赖体量以守住 ≤ 200KB gzip 预算；明确 Web Audio 合成 vs 懒加载预算。
- **致 `/art-bible` 与 `/ux-design`（`art-director` / `ux-designer`）**：
  - 锁定唯一主材质家族语言；落盘校准后的深暖赭黄与深墨棕+亮白脉冲高亮规范；定义棋子外轮廓/底托双通道及棋盘 52 格/虚线航线双通道符号；设计满房/局中/失效链接/微信防误滑退房边缘流、旁观一键认领离线座位入口、静音视觉回合脉冲、桌面端高度驱动等比缩放 + 快捷键 + `prefers-reduced-motion`；为 Alpha-2《极速大富翁》锁死“棋盘格零地名密文”红线。
- **致 `/design-system`（`game-designer`）**：
  - 锁死中式经典飞行棋唯一默认规则表（含叠子/飞跃后连跳/终点折返边界）；设计零数据库房间内多局 Session Scoreboard；定义补位 AI 礼仪（0.4–0.6s 短延迟、不刻意针对领先真人、战报高光聚焦真人）。
- **致 `/test-setup` 与 `/qa-plan`（`qa-lead`）**：
  - 落地 Vitest 三层确定性测试（规则 Golden 快照 + 村规 Pairwise/全组合 + 1,000 局 seeded AI 不变量 Fuzz）；服务端超时与 TTL 支持测试时钟/环境变量注入以加速 Playwright E2E；固化 Week 1 真机微信（iOS+Android）与 iOS Safari 10/10 重连及 `375×540px` 截图留证清单；禁用不可测试主观词（“流畅/爽快/清脆/无感”），统一改用量化断言。
